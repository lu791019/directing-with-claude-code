## UI 視覺檢查（本次的重點）

照任務正常操作，但每到一個新畫面、每進入一個新狀態，都要：

1. 截圖並存檔，檔名記在逐步紀錄。
2. 逐項檢查並記錄（每項寫「有／沒有＋位置」）：
   - 文字被截斷、重疊、超出框線，或要橫向捲動才看得到。
   - 同一個意思重複出現。
   - 按鈕或標籤換行錯位、對不齊。
   - 同一種動作在不同畫面的按鈕顏色、位置、文字不一致。按鈕顏色深淺不同是依重要程度分級，不算；只記「同一種動作」用了不同顏色、位置或文字。
   - 大片沒有內容的空白，或資訊擠成一團。
   - 字太小、太淡，或和背景太接近而看不清。
   - 狀態標籤的顏色和文字是否一致。
3. 只記錄畫面上看得到的現象，不要評論好不好看。
4. 你不知道本系統的設計規範，不要判斷符不符合規範，那由白箱檢查員負責。
